# Lab 6 - Knowledge, Omnichannel, Agent Productivity, Reporting, and Copilot

## Objective

Describe knowledge management, Omnichannel for Customer Service, reporting, data visualization, agent productivity tools, and Copilot in Customer Service.

## Scenario

Contoso agents answer repetitive questions and switch between channels. Management wants a more consistent support experience and better reporting.

## Prerequisites

- Review Customer Service knowledge management.
- Review Omnichannel for Customer Service.
- Review Copilot in Customer Service concepts.

## Tasks

### Step 1 - Design a knowledge article

Create a knowledge article outline:

| Section | Content |
|---------|---------|
| Title | |
| Symptoms | |
| Cause | |
| Resolution steps | |
| Related products | |
| Review owner | |

Use a common issue, such as "Air-conditioner service appointment needs rescheduling."

### Step 2 - Map omnichannel touchpoints

Create a channel table:

| Channel | Customer need | Agent tool |
|---------|---------------|------------|

Include:

- Chat
- Voice
- Email
- SMS or messaging
- Web form

### Step 3 - Define agent productivity tools

Describe how each helps:

- Agent scripts
- Macros
- Knowledge search
- Timeline
- Customer summary
- Copilot case summary
- Suggested responses

### Step 4 - Design service dashboards

Create dashboard requirements:

| Metric | Visualization | Audience |
|--------|---------------|----------|

Include:

- Open cases by priority
- Average response time
- SLA compliance
- Cases by channel
- Agent workload
- Customer satisfaction

### Step 5 - Identify Copilot use cases

Write three use cases:

- Summarize a case
- Draft a customer response
- Suggest relevant knowledge articles

For each, note the human review required.

## Deliverable

Submit:

- Knowledge article outline
- Omnichannel touchpoint table
- Agent productivity notes
- Dashboard requirements
- Copilot use case notes

## Checkpoint questions

1. Why does knowledge management improve service consistency?
2. What problem does omnichannel service solve?
3. Why should Copilot-generated responses be reviewed?
