# Lab 2 - Customer Insights Data, Unified Profiles, Measures, and Predictions

## Objective

Describe how Customer Insights - Data unifies customer profiles and supports measures, segments, and predictions.

## Scenario

Contoso stores customer information in sales records, service cases, appointment history, and marketing forms. Customer names and emails are sometimes duplicated. Management wants one trusted customer profile.

## Prerequisites

- Review Customer Insights - Data concepts.
- Review unified customer profile, measures, segments, and predictions.

## Tasks

### Step 1 - Identify data sources

Create a data source inventory:

| Source | Customer data captured | Business use |
|--------|------------------------|--------------|

Include:

- Sales leads
- Accounts and contacts
- Service cases
- Work orders
- Marketing form submissions
- Event registrations

### Step 2 - Define unification rules

Define matching rules:

| Rule | Matching field | Confidence |
|------|----------------|------------|

Examples:

- Exact email match
- Mobile phone match
- Name plus postal code match

### Step 3 - Build a unified profile sketch

List the fields that should appear in a unified customer profile:

- Name
- Email
- Phone
- Address
- Customer status
- Service assets
- Open opportunities
- Open cases
- Event attendance
- Communication preferences

### Step 4 - Define measures

Create five customer measures:

| Measure | Calculation idea | Business decision supported |
|---------|------------------|-----------------------------|

Examples:

- Total lifetime value
- Number of open cases
- Days since last service visit
- Campaign engagement score
- Renewal likelihood

### Step 5 - Design segments and predictions

Define:

- Two operational segments
- Two marketing segments
- Two possible predictions

For each, describe the action the business could take.

## Deliverable

Submit:

- Data source inventory
- Unification rule table
- Unified profile field list
- Measures table
- Segment and prediction notes

## Checkpoint questions

1. Why is profile unification useful before segmentation?
2. What is the difference between a measure and a segment?
3. How can predictions support customer retention?
