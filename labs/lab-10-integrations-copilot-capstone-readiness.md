# Lab 10 - Teams, Outlook, Excel, Word, SharePoint, Copilot, and Readiness Review

## Objective

Describe Microsoft 365 integrations, Copilot capabilities, and complete a CRM customer engagement capstone map.

## Scenario

Contoso wants users to work from familiar Microsoft 365 tools while keeping CRM data accurate. Leadership also wants to know where Copilot can improve productivity.

## Prerequisites

- Review Microsoft Teams integration with Dynamics 365.
- Review Outlook, Excel, Word, and SharePoint integrations.
- Review Copilot capabilities in customer engagement apps.

## Tasks

### Step 1 - Map Microsoft 365 integrations

Create an integration table:

| Integration | CRM use case | Business value |
|-------------|--------------|----------------|

Include:

- Microsoft Teams
- Outlook
- Excel
- Word
- SharePoint

### Step 2 - Describe common integration scenarios

Write one scenario for each:

- Track an Outlook email against a customer.
- Collaborate on an opportunity in Teams.
- Export a view to Excel for analysis.
- Generate a Word quote or document template.
- Store related documents in SharePoint.

### Step 3 - Create a Copilot use case matrix

Create a table:

| App area | Copilot use case | Human review needed |
|----------|------------------|---------------------|

Include:

- Customer Insights - Journeys
- Sales
- Customer Service
- Field Service
- Core customer engagement apps

### Step 4 - Build the capstone customer engagement map

Create one end-to-end map:

1. Marketing form captures lead.
2. Customer Insights segments the customer.
3. Sales qualifies the lead.
4. Opportunity is managed.
5. Quote is created.
6. Customer signs up for service.
7. Customer raises support case.
8. Case uses knowledge and SLA.
9. Work order is created for field visit.
10. Technician completes inspection.
11. Dashboard reports sales, service, and field outcomes.

### Step 5 - Complete readiness checklist

Create a readiness table:

| MB-910 area | Confidence 1-5 | Evidence from labs | Next study action |
|-------------|----------------|--------------------|-------------------|

Use these areas:

- Customer Insights
- Sales
- Customer Service
- Field Service
- Core customer engagement capabilities

## Deliverable

Submit:

- Microsoft 365 integration table
- Integration scenario notes
- Copilot use case matrix
- End-to-end customer engagement map
- Readiness checklist
