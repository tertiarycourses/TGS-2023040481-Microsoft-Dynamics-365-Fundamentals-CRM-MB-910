# Microsoft Dynamics 365 Fundamentals (CRM) (MB-910) — Hands-On Labs

> **WSQ Course Code:** TGS-2023040481  ·  **Tertiary Infotech Academy Pte Ltd**  ·  [Register](https://www.tertiarycourses.com.sg/wsq-microsoft-dynamics-365-fundamentals-crm-mb-910.html)

Ten guided labs covering the four skill areas measured by Microsoft exam MB-910, plus the core customer engagement capabilities. Every lab has its own folder containing the instructions, a printable PDF and the mock data it needs.

All labs share one scenario: **Contoso Coffee Singapore**, a commercial coffee equipment supplier serving hospitality customers across Singapore. The account you create in Lab 2 is the same account that raises a case in Lab 7 and a work order in Lab 9 — which is exactly how one shared Dataverse behaves.

## Before you start

See [tools.md](tools.md) for the portals, trial options and documentation used across the labs.

1. Sign in to your Dynamics 365 environment (trainer tenant, or a free 30-day trial).
2. Record your user name up to the `@` — that is your **lab alias**.
3. Prefix every record you create with your initials; the class shares one tenant.
4. Never enter real personal data. All supplied mock data uses non-routable example domains.
5. Work through the labs in order — later labs use records created in earlier ones.
